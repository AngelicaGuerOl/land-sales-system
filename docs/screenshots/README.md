# Screenshot Guidelines

[Back to the main README](../../README.md)

Screenshots are portfolio evidence, not a source of real business data. Use demonstration records and review every image before publishing it.

## Capture Guidelines

- Use a consistent browser viewport, preferably 1440 x 900 for desktop captures.
- Capture mobile layouts separately when responsive behavior is relevant.
- Keep the same sidebar state and browser zoom across the main desktop set.
- Prefer full-screen captures that show the relevant workflow without unrelated browser tabs.
- Use concise lowercase filenames with hyphens.
- Do not include credentials, tokens, private URLs, or development console output.

## Information to Anonymize

Replace or remove:

- Real customer names, phone numbers, and addresses.
- Owner or family member names.
- Real sale and payment records.
- Private lot balances or legal land information.
- Coordinates, map annotations, and sensitive reference-plan details.
- Environment variables, passwords, JWT values, and database tools.
